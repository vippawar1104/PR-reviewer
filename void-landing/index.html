01 — Mechanism

Three steps.
No dashboard to babysit.

Void installs as a GitHub App and does its work entirely through webhooks — you never have to open it.

A PULL REQUEST OPENS

GitHub notifies void

The instant a PR opens or gets a new commit, GitHub sends the event straight to void's listener. No polling, no delay.

THE DIFF IS READ

Void reads the change

It pulls the diff and the full content of every touched file, then asks a language model to find real bugs — not style nitpicks.

A VERDICT IS REACHED

It speaks, or it doesn't

Only findings above a severity bar get posted, deduplicated against what it already flagged. Silence means the code passed.

03 — Behavior

Built to be trusted,
not muted.

Every design decision optimizes for one thing: staying installed after week one.

Noise control

Silent by default

Low-severity findings are logged, not posted. A capped, ranked comment count means void never walls-of-text a big diff.

Memory

Never repeats itself

Every finding is remembered. Push again without fixing something and void stays quiet instead of flagging it a second time.

Presence

Lives on your desktop

A native, always-on-top panel — not another tab to check. Green means connected, and it gets out of your way otherwise.

Control

Pause it, or force it

One click silences void mid-sprint. One text field — owner/repo#123 — forces a review on demand, anytime.
